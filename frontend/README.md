# TOEIC Writing Platform Frontend
This is the frontend of TOEIC Writing Platform

## I. Components

|Component      |Library                     |Note|
|---------------|----------------------------|----|
|Main App       |React + TailwindCSS + ShadCN|    |
|Icon           |Lucide                      |    |
|Module Bunler  |Vite                        |    |
|API module     |Axios with Hey-API          |    |
|Package Manager|Yarn Berry                  |    |  

## II. Pages

|Page                                          |Function              |
|----------------------------------------------|----------------------|
|`/`                                           |Dashboard             |
|`/topic/new`                                  |Create new topic      |
|`/topic/{topic_id}`                           |Detail of topic       |
|`/topic/{topic_id}/submit`                    |Submit essay for topic|
|`/topic/{topic_id}/submission/{submission_id}`|Submission review     |
